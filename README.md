# TavernDiceRoller
## This is a diceroller and character creator designed initially for any d20 system. While this still works, it is now focused on D&D 5e in the character creator setting. This was designed for fans of D&D and TTRPGs who want something more polished than the available third party resources which normally are either a dice roller or a character creator.
## Installation
-> Download the REPO
-> open the console using shift + ` and run npm install which will install all file dependancies.
-> 
## Usage
-> Navigate from the landing to the dice roller where you can generate a standard 4d6 drop lowest character or roll dice and keep a record.
-> The character sheet is form to be filled out, but is not currently able to be saved.
-> To start hit the roll character button which will fill in stats randomly; hit until you're happy.
-> Skills, Equipment and Attacks are meant to be customizable with the "add x" buttons. These create inputs which can be filled in.
-> Follow your other online resources such as https://dnd5e.wikidot.com/ to fill in the sheet.
## Notes
-> strictly speaking you do not require the backend for this to function and do not need to log in.
-> Updates to save or download the sheet will be worked on.
